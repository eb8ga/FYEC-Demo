# Tool safety

One folder per tool. Read the tool's page before you use it, and use it only after someone has shown you how.

| Tool | Used for |
| --- | --- |
| [Heat-set insert press](heat-set-insert-press/README.md) | Installing brass threaded inserts in the 3D-printed enclosure |

## Rules for every tool

- Wear safety glasses.
- Tie back long hair. Roll up loose sleeves. No dangling cords or lanyards.
- Keep the work area clear. Only the part you are working on, and the tools you need.
- Know where the power switch and the plug are before you turn a tool on.
- Never leave a powered tool unattended.
- If something looks, smells or sounds wrong, stop, turn it off and tell the instructor.

## Burns

Cool the burn under cool running water for 20 minutes. Do not use ice. Tell the instructor.
