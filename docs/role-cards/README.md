# Role cards

Each role gets one printed card. Each card holds facts the rest of the team needs.

| Card | Role | Build step |
| --- | --- | --- |
| [01-sensor](01-sensor.md) | Sensor | 1 |
| [02-microcontroller-and-code](02-microcontroller-and-code.md) | Microcontroller + Code | 1, 2 and 5 |
| [03-power](03-power.md) | Power | 2 |
| [04-human-interaction](04-human-interaction.md) | Human Interaction | 3 |
| [05-mechanical](05-mechanical.md) | Mechanical | 4 and 6 |

Six people: two share the Microcontroller + Code card.

## Build order

| Step | Who | What |
| --- | --- | --- |
| 1 | Sensor + Microcontroller + Code | Plug the sensor into the STEMMA QT port. |
| 2 | Power + Microcontroller + Code | Wire the charger, switch and QT Py into the power board. Switch OFF. |
| 3 | Human Interaction | Chain the OLED from the sensor's free port. Seat the light pipes. |
| 4 | Mechanical | Seat every part in the case. Lid stays off. |
| 5 | Microcontroller + Code, with everyone | Power on, program your application's set points, test. |
| 6 | Mechanical | Close the case once the test passes. |
